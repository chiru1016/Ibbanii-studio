# Ibbanii Studio

Full-stack handmade craft ecommerce application.

- React + Vite frontend
- Node.js + Express backend
- MongoDB Atlas database
- Razorpay payments
- Firebase authentication
- Cloudinary product image storage
- Render backend
- Vercel frontend

## Product images

Admin users can select an image from their computer/gallery from the Add Product page. The backend uploads it to Cloudinary and stores the resulting secure URL in MongoDB.

See `CLOUDINARY_SETUP.md`.
